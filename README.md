# Student Attendance Management System

## Project Description

The Student Attendance Management System is a Java-based application that helps manage student attendance records. It allows users to register students, mark attendance, search for students, and calculate attendance percentages.

## Features

* Add student details
* View registered students
* Mark students as present or absent
* Generate attendance reports
* Calculate attendance percentage
* Search students by ID

## Technologies Used

* Java
* Object-Oriented Programming
* ArrayList
* Scanner

## How to Run

1. Install the Java Development Kit (JDK).

2. Download or clone this repository.

3. Open the project folder in a terminal.

4. Compile the program:

   `javac StudentAttendance.java`

5. Run the program:

   `java StudentAttendance`
